## Built with

Plain HTML, CSS, and JavaScript, with no frameworks or build step. Hosted on GitHub Pages.

- Responsive layout down to phone width
- Light and dark themes (follows the system setting, with a manual toggle)
- Accessible navigation: skip link, keyboard-friendly menu, reduced-motion support

## Structure

```
pukarpuri17.github.io/
├── index.html   # Page content
├── styles.css   # Styles and themes
├── script.js    # Mobile menu, theme toggle, scroll effects
└── .nojekyll    # Tells GitHub Pages to serve files as-is
```

## Run locally

```bash
git clone https://github.com/PukarPuri17/pukarpuri17.github.io.git
cd pukarpuri17.github.io
python3 -m http.server 8000   # then open http://localhost:8000
```

Changes pushed to `main` are published automatically by GitHub Pages.
